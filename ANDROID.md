# Cassette.fm Android app

The app is the same Angular code as the website, wrapped with [Capacitor](https://capacitorjs.com).
GitHub builds the APK for you — nothing to install on your computer.

## What the app adds

| | |
|---|---|
| **Offline downloads** | ⤓ next to any song, or **Download** at the top of a playlist. Songs are saved inside the app and play with no internet. Covers are saved too. |
| **Downloads playlist** | Button next to ♥ Liked (and in the ☰ menu). Offline, the player skips straight to downloaded songs. |
| **Plays with the screen off** | A media notification with the album cover, ⏮ ⏯ ⏭ and a seek bar: always visible (also collapsed), on the lock screen, in Android's Quick Settings media player, and from headphone / Bluetooth / car buttons. If notifications are off, Settings shows a **Turn on** button. |
| **Phone layout** | Logo and profile on top; **Home · Search · Latest · Library · Settings** in a bottom bar; compact player. |
| **Settings (⚙ in the header)** | Colour (6 accents), background (Dusk, Midnight/AMOLED, Ocean, Monsoon, Sunrise), floating lights on/off, 5-band equaliser with presets, even-out-loudness, fade between songs, sleep timer, Wi-Fi-only downloads, auto-download liked songs, storage used, remove all downloads. |
| **Your Library** | ☰ → Your Library: own playlists, smart playlists from your plays, filters, sort, grid, pins, Recently deleted, export/import (saved to Documents/Cassette.fm). |
| **Sound** | 10-band EQ + 14 presets, bass, treble, volume boost, stereo width/mono, balance, 8D audio, Space reverb, speed, your own presets. |
| **Latest & Trending** | New songs per language (YouTube, screen on), Top 100 India (Apple previews), Spotify. See LATEST.md / SPOTIFY.md. |
| **Accounts** | Sign up with email or Google; liked songs and settings follow the listener to any phone. Needs a free Firebase project: see **[ACCOUNTS.md](ACCOUNTS.md)**. |
| **Voice search** | 🎤 in the search bar: say a song, film or singer ("play Tujhe Dekha To"). Uses Android's own speech recognition (English-India, which writes Hindi/Tamil/Kannada song names the way playlists spell them). Also works on the website in Chrome, Edge and Safari. |
| **Back button** | Closes menus; on the home screen it sends the app to the background instead of stopping the music. |

The website gets all of this too (downloads are kept in the browser), plus a **Get the Android app** link.

## One-time setup (5 minutes)

1. **Upload this folder to your `Cassette.fm` GitHub repo** (replace the old files). Keep the `android/` folder.
2. **Add the signing key as secrets.** Open `SIGNING-KEY-README.txt` (sent separately, *not* in the repo) and add the 4 secrets under
   **Settings → Secrets and variables → Actions → New repository secret**:
   `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
   Back up `cassette-release.jks` somewhere safe — every future update must be signed with it.
3. **Build:** push to `main`, or go to **Actions → Build Android app → Run workflow**. It takes about 6–8 minutes.
4. **Get the APK:** **Releases** on the repo's main page → `Cassette.fm.apk`. This link always gives the newest one:
   `https://github.com/<your-username>/Cassette.fm/releases/latest/download/Cassette.fm.apk`

Share that link. On the phone: open it → **Download** → **Install** (allow "Install unknown apps" for the browser when asked).
Installing a newer APK updates the app and keeps downloads and liked songs.

## Files

```
capacitor.config.ts                      app name, ID (fm.cassette.app), splash colour
android/                                 the Android project (generated by Capacitor, plus our own code below)
  app/src/main/java/fm/cassette/app/
    MainActivity.java                    starts the app, registers our plugin
    PlaybackPlugin.java                  web code ↔ Android: "Now playing" notification + its buttons
    PlaybackService.java                 the foreground service that keeps music going with the screen off
  app/src/main/AndroidManifest.xml       permissions (internet, notification, background playback)
assets/                                  icon and splash source images (regenerate: npx capacitor-assets generate --android)
src/app/
  services/native.service.ts             app-only bits: internet/Wi-Fi state, notification, back button
  services/downloads.service.ts          offline downloads (app: files; website: IndexedDB)
  services/settings.service.ts           all settings + colour themes (backgrounds live in styles.scss)
  services/audio-fx.service.ts           equaliser + loudness levelling (Web Audio)
  components/settings-panel/             the ⚙ Settings screen
  components/download-button/            ⤓ button with progress ring
  services/account.service.ts            accounts (Firebase) + backup of likes and settings
  components/account-screen/             welcome / sign up / log in screens
  data/app-info.ts                       repo name + version (filled in by the workflows)
.github/workflows/android.yml            builds the APK and publishes the release
```

## Build on your own computer (optional)

Needs [Android Studio](https://developer.android.com/studio).

```bash
npm install
npm run build
npx cap sync android
npx cap open android      # then ▶ Run in Android Studio, with your phone plugged in
```

## Good to know

- **Play Store:** this setup makes an APK to share directly. The Play Store needs an `.aab`
  (`./gradlew bundleRelease`) and a developer account. Fan-uploaded film songs may not pass Play Store review.
- **Equaliser / even-out-loudness** switch songs to archive.org's `/cors/` address, which Web Audio needs.
  If a song won't play with them on, turn them off.
- Downloads are app-private: they're removed if the app is uninstalled, and don't show up in other music apps.
